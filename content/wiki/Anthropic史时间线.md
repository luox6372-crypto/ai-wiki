# Anthropic 史时间线（2016–2026）

> 本时间线以原始 SRT 中的事件年份为锚点。带 ⚠ 标记的条目是 SRT 转写错误，已在条目正文中给出正名。confidence: low 的条目多为 SRT 的政治判断与立场性叙述。

## 2016–2020：OpenAI 时代

- **2016** — [[wiki/人物/Anthropic史/达里奥·阿莫代|达里奥·阿莫代]] 与 [[wiki/人物/Anthropic史/丹妮拉·阿莫代|丹妮拉·阿莫代]] 是 OpenAI 早期核心成员；Greg Brockman 常在客厅与他们长谈"AI 技术路线与人类命运"。来源：srt。
- 深夜分歧：Brockman 提出把 AGI 核心代码交给联合国安理会五常"互相制衡"，Dario 视为"同时向几个大国兜售毁灭世界的超级武器"。来源：srt。
- **2019** — 微软入股 OpenAI + 拿下 GPT-3 独家商业授权，公司基因改变。来源：srt。
- **2020** — Sam Altman 推行"去学术化改革"，考核从"让人类福祉最大化"换成"每秒多少请求、估值抬到多高"。来源：srt。
- Dario 坚持训练前过滤暗网数据；Altman 主张"小步快跑、灰度试错"。来源：srt。
- 2020 董事会上 Altman 公开指控 Amodei 兄妹"串联核心研究员递交负面报告"；丹妮拉当众对质线人，线人当场否认。来源：srt。
- **2020-12** — Dario 和 Daniela 正式辞职，带走近十位核心科学家，含 [[wiki/人物/Anthropic史/杰拉德·卡普兰|杰拉德·卡普兰]]。来源：srt。

## 2021：公园折叠椅上的 Anthropic

- **2021 初** — 旧金山疫情中，竞业协议敏感期，七位创始人"拎着几十块钱的廉价露营折叠椅在公共公园围坐成一圈、戴口罩、顶着寒风"开会。来源：srt。
- 起名 "Anthropic"——源自宇宙学的[[wiki/概念/Anthropic史/人择原理与公司命名|人则原理]]。来源：srt。
- 注册为[[wiki/概念/Anthropic史/公共利益公司PBC|公共利益公司 PBC]]。来源：srt。
- 创始股权 7 人完全均分；承诺 2026 年初捐出个人财富 80%。来源：srt。
- **2021-05** — A 轮 1.24 亿美元（估值未对外公布）。来源：srt。
- **2021-05-28** — 第一次对外亮相日（5 周年时是 2026-05-28 H 轮公布日）。来源：srt。

## 2022：起跑期

- 2022 期间在安全研究上做大量准备（具体里程碑 SRT 未展开）。来源：srt。
- 公司内部集体迷上加州科学院一只叫 CLAUDE 的白色短吻鳄——办公室堆满鳄鱼玩偶、定制表情包、屏幕常开白鳄直播。来源：srt。

## 2023：Claude 1 → Claude 2.1

- **2023-03** — Claude 1 首次亮相，定位"有用、诚实、无害"的 AI 助手。来源：srt。
- **2023** — 谷歌战略投资约 3 亿美元，估值锚定 41 亿美元。来源：srt。
- **2023-07** — Claude 2 网页公测。来源：srt。
- **2023-09** — Claude Pro 每月 20 美元付费版。来源：srt。
- **2023-11** — Claude 2.1：以"超长上下文、可调用外部工具、更低胡说率"建立企业级口碑。来源：srt。

## 2024：Claude 3 + Artifacts + Computer Use + MCP

- **2024-03** — [[wiki/概念/Anthropic史/Claude模型家族|Claude 3 家族]] 一口气推 3 个版本：Haiku（轻量快）、Sonnet（均衡）、Opus（最强）。来源：srt。
- **2024-06** — Claude 3.5 + [[wiki/概念/Anthropic史/Artifacts工作面|Artifacts]]：把"回答你问题的人"变成"并肩工作的界面"。来源：srt。
- **2024-10** — [[wiki/概念/Anthropic史/Computer-Use|Computer Use]]：模型能截屏看懂电脑屏幕、自己移动光标、点击按钮、输入文字。来源：srt。
- **2024 末** — 发布 [[wiki/概念/Anthropic史/MCP模型上下文协议|MCP（Model Context Protocol）]]。来源：srt。
- **2024 年底** — ARR 冲至 10 亿美元。来源：srt。

## 2025：Claude Code 起飞

- **2025-02** — Claude 3.7 + [[wiki/概念/Anthropic史/Claude-Code|Claude Code]]：把模型从聊天框伸出去，做"有高度自主权、能多步连续作业的虚拟软件工程师"。来源：srt。
- **2025-03** — 估值 615 亿美元。来源：srt。
- **2025-09** — 5 年后（2026-05）H 轮公布日定档。来源：srt（推算）。
- **2025 下半年** — F 轮估值 1830 亿美元；ARR 从 90 亿冲到 120 亿。来源：srt。
- **2025 下半年** — 30 万+ 商业和企业客户、贡献 80% 收入；年花费 >10 万美元大客户数翻 7 倍。来源：srt。

## 2026：估值破 9000 亿、首次运营利润转正

- **2026-01** — MCP 月下载量破 1 亿。来源：srt。
- **2026-02** — Claude Code ARR 破 25 亿美元；G 轮估值 3800 亿。来源：srt。
- **2026 初** — 500+ 百万美元客户；财富前 10 企业中 8 家是客户；七位联合创始人承诺捐出 80% 个人财富（兑现）。来源：srt。
- **2026** — 推出 Cowork、Claude Design 等功能；产品哲学转向"工作中的智能基础设施"。来源：srt。
- **2026-05-28** — H 轮 650 亿美元融资公布；投后估值 9650 亿美元；ARR 470 亿美元；季度运营利润首次转正。来源：srt。
- **2026 Q2（预计）** — 首次运营利润约 5.59 亿美元。来源：srt。
- **2026 之后 2 个月** — 百万美元客户从 500 突破 1000。来源：srt。
- **2026** — 全球每 100 行新写代码中 4 行由 Claude Code 完全自主写出并自动合并。来源：srt。
