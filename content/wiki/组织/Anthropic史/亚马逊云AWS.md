# 亚马逊云（AWS）

> 来源：[原始字幕 (SRT)](raw/Anthropic史：从OpenAI叛逃者，到估值万亿的AI帝国.srt)（条目 663–673、683–685）
> ⚠ SRT 中 "Amazon" 出现为 "亚马逊" / "亚马逊云"——本条目使用规范名"亚马逊云（AWS）"。

## 一句话

亚马逊云（AWS）是 Anthropic 最重要的算力与渠道盟友——150 亿美元注资承诺 + 5GW 定制芯片算力 + 企业销售渠道倾斜。来源：srt。

## 与 Anthropic 的关系

- SRT 描述："他们首先拉来了亚马逊云做深度结盟，接受他高达 150 亿美元的注资承诺，但这笔钱定向变成了亚马逊定制芯片的算力额度，和他云平台上的旗舰流量倾斜。"来源：srt。
- "靠这一步，Anthropic 瞬间吸走了亚马逊庞大的企业销售渠道。"来源：srt。
- 在 2026-05 H 轮融资后，"亚马逊云提供 5GW 的定制芯片算力，专门用来训练它最顶级的旗舰模型"。来源：srt。

## SRT 视角的"算力对冲"

- "为了防止亚马逊一家独大形成新的垄断，他们又拉来谷歌做对等的制衡。"来源：srt。
- "通过这套多级算力主权的打法，Anthropic 不仅给自己保障了源源不断的物理燃料，更在公司的控制权和独立性上筑起了一道坚不可摧的防火墙——没有任何一家云巨头能够靠断供算力这一招来要挟 Anthropic 的技术路线。"来源：srt。

## 与本知识库的连接

- 与 [[wiki/组织/DeepMind全史/微软|微软]]（DeepMind 全史版）的对比：SRT 把 OpenAI 描述为"把灵魂和技术独家抵押给微软云"；Anthropic 则多极对冲。
- 与 [[wiki/概念/Anthropic史/Anthropic商业模式三层|商业模式三层]] 的关系：AWS 既是底层 API 服务的算力来源，也是中层（企业级工作产品）的销售渠道。
