# 阿卡迈（Akamai）

> 来源：[原始字幕 (SRT)](raw/Anthropic史：从OpenAI叛逃者，到估值万亿的AI帝国.srt)（条目 693–697）
> ⚠ SRT 中 "Akamai" 被转写为 "阿卡迈"——本条目使用规范名"阿卡迈（Akamai）"。

## 一句话

内容分发巨头 Akamai（阿卡迈）与 Anthropic 签下 18 亿美元全球边缘缓存大单——确保 Claude Code 等自主代理在全球各地企业本地部署时"接近本地原声"的响应速度。来源：srt。

## 与 Anthropic 的关系

- SRT 描述："内容分发巨头阿卡迈则签下了一份价值 18 亿美元的全球边缘缓存大单，确保 Claude Code 这类自主代理在全球各地的企业本地部署时都能有接近本地原声的响应速度。"来源：srt。
- 是 Anthropic"多极算力主权"算盘里的关键一环——边缘层而非中心算力。来源：srt。

- 与 [[wiki/组织/Anthropic史/亚马逊云AWS|亚马逊云 AWS]]、SpaceX、谷歌云一起构成 [[wiki/概念/Anthropic史/Anthropic商业模式三层|商业模式三层]] 底层的算力版图。
