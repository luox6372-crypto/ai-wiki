# Claude 模型家族

> 来源：[原始字幕 (SRT)](raw/Anthropic史：从OpenAI叛逃者，到估值万亿的AI帝国.srt)（条目 261–320、339–354）
> ⚠ SRT 中 "Claude" 被频繁转写为 "cloud" / "Cloud" / "claude"——本条目使用规范名"Claude"。

## 一句话定义

Anthropic 自 2023-03 起推出的 LLM 家族，至 2026-05 已迭代至 Claude 4；2024-03 起形成 Haiku（轻量快）/Sonnet（均衡好用）/Opus（能力最强）三层产品线。来源：srt。

## 时间线

- **2023-03** — Claude 1 首次亮相，定位"有用、诚实、无害"的 AI 助手。来源：srt。
- **2023-07** — Claude 2 网页公测。来源：srt。
- **2023-09** — Claude Pro 每月 20 美元付费版。来源：srt。
- **2023-11** — Claude 2.1：超长上下文、可调用外部工具、更低胡说率，确立企业级口碑。来源：srt。
- **2024-03** — Claude 3 家族一口气推出 3 个版本：Haiku（轻量快）、Sonnet（均衡好用）、Opus（能力最强）——"这下企业终于可以按自己的场景挑着买智能了"。来源：srt。
- **2024-06** — Claude 3.5 + [[wiki/概念/Anthropic史/Artifacts工作面|Artifacts]]。来源：srt。
- **2024-10** — Claude 3.5 + [[wiki/概念/Anthropic史/Computer-Use|Computer Use]]。来源：srt。
- **2024 末** — Claude 3.5 系列扩展 + [[wiki/概念/Anthropic史/MCP模型上下文协议|MCP 协议]] 发布。来源：srt。
- **2025-02** — Claude 3.7 + [[wiki/概念/Anthropic史/Claude-Code|Claude Code]]。来源：srt。
- **2026** — Claude 4 系列（推算）；Cowork、Claude Design 等功能陆续登场。来源：srt。

## 产品哲学

- SRT 描述：Anthropic "慢慢长出了另一种野心——不只是做那个最聪明的模型，而是做那个最像能来上班的模型"。来源：srt。
- 不是"全网最火的聊天机器人"，而是"最能被企业放心、接近自家工作流的那个模型"。来源：srt。
- 企业级市场细分：长文档 → 复杂指令 → 专业活。来源：srt。

## 内部梗：白鳄 Claude

- 公司内部集体迷上加州科学院一只叫 CLAUDE 的白色短吻鳄。来源：srt。
- 办公室堆满鳄鱼玩偶、内部聊天软件有专门定制的鳄鱼表情、屏幕常年挂着白鳄鱼直播。来源：srt。
- "一半是硬核到极致的工程，一半是高度自我调侃的呆萌幽默"——Anthropic 的内部气质。来源：srt。
