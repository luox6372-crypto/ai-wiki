# Claude Code

> 来源：[原始字幕 (SRT)](raw/Anthropic史：从OpenAI叛逃者，到估值万亿的AI帝国.srt)（条目 338–463）
> ⚠ SRT 中 "Claude Code" 被转写为 "cloud code" / "Cloud code"——本条目使用规范名"Claude Code"。

## 一句话定义

Anthropic 在 2025-02 随 Claude 3.7 推出的命令行编程代理——"有高度自主权、能多步连续作业的虚拟软件工程师"；2026-02 ARR 破 25 亿美元，成为企业软件史上最快突破百亿美元营收级别的爆款之一。来源：srt。

## 关键能力

- 直接扫描企业几百万行代码。来源：srt。
- 在命令行里自己读报错日志、做逆向分析、设计测试用例、自动找 bug。来源：srt。
- 把改好的代码直接提交上去。来源：srt。
- 与"AI 副驾驶"（Copilot）的根本区别：人类不再写一句让 AI 补一句；Claude Code 自主规划、连续作业。来源：srt。

## 商业奇迹

- 发布后 6 个月实现 10 亿美元年化收入。来源：srt。
- 2026-02 翻倍到 25 亿美元。来源：srt。
- 2026-05 时 Anthropic 整体 ARR 470 亿美元，Claude Code 是其中最强劲的引擎。来源：srt。
- SRT 数据：2026 年全球软件开发者每天提交的代码里有 4% 由 Claude Code 完全自主写出并自动合并。来源：srt。
- 2026-02 季度 Claude Code 企业订阅量比年初翻了 4 倍。来源：srt。

## SRT 的"经济学账本"

> "在硅谷雇一个高水平程序员一年得花 30 万美元，而部署一套 Claude Code 开无限多个并发实例，每个月企业订阅费也就几百美元，再加上按量付费的接口调用——他不会累、不需要交社保、不用买医疗保险，还能在几秒钟内理清原本要一整个团队啃上好几周才能搞明白的代码架构。"来源：srt。

## Dario 的方法论

SRT 引用 Dario 的采访原话："代码之所以最先爆发，不只是因为模型擅长写代码，更因为程序员这个群体离模型开发者最近，无论是社交距离还是技术距离，新技术扩散到他们身上的阻力都最小。"来源：srt。
