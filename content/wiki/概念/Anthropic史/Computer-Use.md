# Computer Use

> 来源：[原始字幕 (SRT)](raw/Anthropic史：从OpenAI叛逃者，到估值万亿的AI帝国.srt)（条目 315–320）

## 一句话定义

Anthropic 在 2024-10 发布的功能——让 Claude 能通过截屏看懂电脑屏幕、自己移动光标、点击按钮、输入文字，"目标就是让 Claude 真正学会用电脑干活"。来源：srt。

## 关键能力

- 截屏看懂屏幕。来源：srt。
- 自己移动光标。来源：srt。
- 点击按钮、输入文字。来源：srt。

## 在产品矩阵中的位置

- 与 [[wiki/概念/Anthropic史/Claude-Code|Claude Code]] 一脉相承——"把模型从聊天框里伸出去"。来源：srt。
- 与 [[wiki/概念/Anthropic史/MCP模型上下文协议|MCP 协议]]（2024 末）一起，构成 Anthropic 把"AI 代理"从概念变成基础设施的两大支撑。
- 与 [[wiki/概念/AI简史/智能体Agent|智能体 Agent]]（AI 简史版）的关系：Computer Use 是"用电脑的代理"的具体形态。
