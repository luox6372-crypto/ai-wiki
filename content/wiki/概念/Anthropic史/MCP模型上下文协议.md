# MCP（Model Context Protocol）

> 来源：[原始字幕 (SRT)](raw/Anthropic史：从OpenAI叛逃者，到估值万亿的AI帝国.srt)（条目 322–336）
> ⚠ SRT 中 MCP 的全称写作"模型上下文协议"——本条目使用规范名 MCP（Model Context Protocol）。

## 一句话定义

**MCP（Model Context Protocol，模型上下文协议）**——Anthropic 在 2024 末发布的开放标准，后来几乎成为所有 AI 代理"连接工具和数据的通用接口"；2026-01 月下载量破 1 亿次。来源：srt。

## 在 Anthropic 战略中的位置

- SRT 评价："对分析师来说，这件事的价值甚至不亚于一次大的模型升级——因为它意味着 Anthropic 不止想赢'谁的模型更强'这场仗，他还想赢'模型该怎么和真实世界打交道的标准制定权'。"来源：srt。
- "而一旦你掌握了标准，你占住的位置，就比单独某一个模型版本要稳固得多。"来源：srt。

## 与"代理基础设施"的连接

- MCP + [[wiki/概念/Anthropic史/Computer-Use|Computer Use]] + [[wiki/概念/Anthropic史/Claude-Code|Claude Code]] 三件套，构成 Anthropic 把"AI 代理从概念变成可部署的基础设施"的产品矩阵。
- 与 [[wiki/概念/Anthropic史/Anthropic商业模式三层|商业模式三层]] 的关联：MCP 让"高合规企业客户的工具接入"标准化，是中间层（企业级工作产品）的关键粘性来源。
