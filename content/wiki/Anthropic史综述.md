# Anthropic 史综述

> 本文是 Anthropic 的公司传记式综述页。原始资料为一段商业科普视频字幕。**SRT 中存在大量转写错误（cloud=Claude、artifacts=Artifacts、computer use=Computer Use、MCP 等）和拼写差异（达里奥=Dario、丹妮拉=Daniela、卡普兰=Kaplan 等），本文以规范译名/正名呈现，并在概念页中以 ⚠ 注释。末段对地缘政治与中国相关议题的评论属 SRT 作者的立场，标 `confidence: low` 并显式归因到 SRT。**

## 一句话主线

一群在 OpenAI 目睹"安全让位商业"的核心科学家，带着 GPT-3 第一作者出走；用 5 年时间把一家从公园折叠椅上起步的初创，做成 ARR 470 亿美元、估值 9650 亿美元的"安全 AI 帝国"——并被 SRT 描述为"屠龙少年终成恶龙"。来源：[原始字幕 (SRT)](raw/Anthropic史：从OpenAI叛逃者，到估值万亿的AI帝国.srt)。

## 章节地图

1. **从 OpenAI 到反目（2016–2020）**
   - [[wiki/人物/Anthropic史/达里奥·阿莫代|达里奥·阿莫代]] 与 [[wiki/人物/Anthropic史/丹妮拉·阿莫代|丹妮拉·阿莫代]] 是 OpenAI 早期核心成员；与 Greg Brockman 常深夜长谈。来源：srt。
   - 分歧种子：Brockman 提出把 AGI 核心代码交给联合国安理会五大常任理事国"互相制衡"，Dario 视为"同时向几个大国兜售毁灭世界的超级武器"。来源：srt。
   - 2019 微软入股 OpenAI + 拿下 GPT-3 独家商业授权，公司基因改变。来源：srt。
   - Sam Altman 推行"去学术化改革"，考核从"让人类福祉最大化"换成"每秒多少请求、估值抬到多高"。来源：srt。
   - Dario 坚持训练前过滤暗网数据；Altman 主张"小步快跑、灰度试错"。来源：srt。
   - 2020-12 达里奥和丹妮拉正式辞职，带走近十位核心科学家，含 GPT-3 第一作者 [[wiki/人物/Anthropic史/杰拉德·卡普兰|杰拉德·卡普兰]]。来源：srt。
2. **公园折叠椅上的起步（2021）**
   - 2021 初旧金山疫情中竞业协议敏感期，七位创始人"拎着几十块钱的廉价露营折叠椅在公共公园围坐成一圈、戴口罩、顶着寒风"开始。来源：srt。
   - 公司名 "Anthropic" 取自宇宙学的[[wiki/概念/Anthropic史/人择原理与公司命名|人则原理]]——"只有物理常数精准的宇宙才能孕育出能回头观测它的智慧生命"。来源：srt。
   - 注册为[[wiki/概念/Anthropic史/公共利益公司PBC|公共利益公司 PBC]]："当利润和人类安全冲突时，可以毫无顾虑地选择安全"。来源：srt。
   - 创始股权 7 人完全均分；承诺至 2026 年初捐出个人财富 80%。来源：srt。
3. **Claude 产品矩阵（2023–2026）**
   - 2023-03 Claude 1 学术定位（有用、诚实、无害）。来源：srt。
   - 2023-07 Claude 2 网页公测、09 Claude Pro 20 美元/月。来源：srt。
   - 2023-11 Claude 2.1 拉开"长文档、工具调用、低胡说率"的企业级差异。来源：srt。
   - 2024-03 [[wiki/概念/Anthropic史/Claude模型家族|Claude 3 家族]]（Haiku/Sonnet/Opus）。来源：srt。
   - 2024-06 Claude 3.5 + [[wiki/概念/Anthropic史/Artifacts工作面|Artifacts]]。来源：srt。
   - 2024-10 [[wiki/概念/Anthropic史/Computer-Use|Computer Use]]。来源：srt。
   - 2024 末 [[wiki/概念/Anthropic史/MCP模型上下文协议|MCP]]；2026-01 月下载量破 1 亿。来源：srt。
   - 2025-02 Claude 3.7 + [[wiki/概念/Anthropic史/Claude-Code|Claude Code]]；2026-02 Claude Code ARR 破 25 亿美元。来源：srt。
   - 2026 Cowork、Claude Design 陆续登场。来源：srt。
4. **商业飞轮（2024–2026）**
   - 28 个月内 ARR 从 8700 万美元到 470 亿美元。来源：srt。
   - 2025 下半年 30 万企业客户、贡献 80% 收入；2026 初 500+ 百万美元客户、2 个月后破 1000。来源：srt。
   - 平均每个客户年合同价值 2000 万美元；全球前 10 跨国银行中 7 家是客户。来源：srt。
   - [[wiki/概念/Anthropic史/Anthropic商业模式三层|商业模式三层]]：API 与模型服务 / 企业级工作产品 / 个人订阅。来源：srt。
   - 预计 2026 Q2 首次运营利润 5.59 亿美元；2026-05 季度运营利润首次转正。来源：srt。
5. **融资与算力布局**
   - 股权融资：A 轮 1.24 亿 → 2023 谷歌战略投资 3 亿（估值 41 亿）→ 2025-03 估值 615 亿 → F 轮 1830 亿 → 2026-02 G 轮 3800 亿 → 2026-05 H 轮 65 亿（投后 9650 亿）。来源：srt。
   - 战略资本：[[wiki/组织/Anthropic史/亚马逊云AWS|亚马逊云]] 150 亿美元注资承诺 + 5GW 定制芯片、谷歌 5GW 自研芯片、SpaceX 共享超级算力、Akamai 18 亿美元全球边缘缓存。来源：srt。
   - 多元算力对冲是 Anthropic 主动设计的"防火墙"——"没有任何一家云巨头能靠断供算力来要挟 Anthropic 的技术路线"。来源：srt。
6. **企业级降维打击的法务-技术-财务三轴**
   - 法务：[[斯特莱普Stripe|Stripe]] 出身的丹妮拉定下"数据物理隔离、用完即焚"、版权侵权无限额赔偿。来源：srt。
   - 技术：[[wiki/概念/Anthropic史/机械可解释性|机械可解释性]] 让客户可"在代码层面关掉负责瞎猜的神经元"。来源：srt。
   - 财务：平均年合同 2000 万美元；OpenAI 走中小企业/独立开发者高频低单价，Anthropic 走金字塔顶端"高合规高客单价的超级掠食者"。来源：srt。
7. **SRT 末段的"屠龙少年"反思（confidence: low）**
   - SRT 主张："Anthropic 在模型训练和安全策略里系统性地嵌入对特定国家的偏见与攻击"——这是 SRT 作者的立场判断，非中立事实。来源：srt。
   - SRT 主张："他曾经痛斥 OpenAI 被微软资本绑架、被商业指标绑架，如今自己却深度绑定亚马逊、谷歌、微软三大云巨头"。来源：srt。
   - SRT 主张："他曾经警告能力火箭式膨胀而刹车跟不上会酿成大祸，如今却把 Claude Code / Computer Use 这些高自主权的代理功能以惊人的速度推向全球企业——这背后正是他最先批评的那种小步快跑、灰度试错"。来源：srt。
   - 结尾反问："Anthropic 究竟是还在守护初心，还是早已在不知不觉中从屠龙少年变成了恶龙？"——这是 SRT 的反诘式结论。来源：srt。

## 反复出现的主题

- **安全即商业护城河**："在这个信任稀缺的时代，一个 AI 系统的安全程度和企业愿意为他掏出来的钱成绝对的正比。"来源：srt。
- **算力即主权**：多级算力对冲（亚马逊 + 谷歌 + SpaceX + Akamai）是 Anthropic 主动设计的"独立防火墙"。来源：srt。
- **从学术到产品**：Dario 和 Daniela 的路径是"把安全研究翻译成工作流产品"——Claude、Artifacts、Computer Use、MCP、Claude Code 一脉相承。来源：srt。
- **理想主义的成本**：7 人均分股权 + 80% 财富捐赠承诺，是 Anthropic 与 OpenAI 在治理与文化上的最显著差异。来源：srt。
- **屠龙者的悖论（confidence: low）**：SRT 视角下，Anthropic 在反 OpenAI 之后复制了自己批评的几乎所有行为——这本身是商业组织演化的常见模式，但仍属 SRT 立场判断。
