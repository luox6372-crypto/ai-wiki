# raw / wiki / output 结构说明

## 核心思路

- `raw/`：raw，原始资料。收集，不动。
- `wiki/`：wiki，LLM 编译出来并长期维护的 Markdown 知识库。
- `output/`：output，基于 wiki 产出的文章、报告、课件或其他交付物。
- `.llmwiki/`：插件隐藏后台，不是 Karpathy 三桶之一。

## 必备字段

知识笔记建议包含：

```yaml
type: note
summary: 一句话摘要
aliases: []
sources: []
created: YYYY-MM-DD
updated: YYYY-MM-DD
reviewed: false
confidence: medium
```
